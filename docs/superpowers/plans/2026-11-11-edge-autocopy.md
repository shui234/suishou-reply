# V1.2.1 生成后自动复制

用户希望进一步减少复制操作，保留人工粘贴与发送。在已有 V1.2 上增量实现，复用 Native Messaging、凭据、请求与提示词；不碰已有桌面未提交修改。

设计：独立 autoCopy 开关，默认关闭，浏览器本地持久保存。相对始终自动复制，显式开关让用户能控制剪贴板替换；相对新增后台剪贴板服务，直接使用已有 content script 和 clipboardWrite 权限无需额外权限。仅接受当前有效请求结果时触发，不把 UI render 当作复制事件。验证前台、正文身份、编辑版本、长度；失败不重试。异步返回的反馈检查页面与草稿仍匹配。

完成路径：先增加结果、竞争、设置与失败测试并观察失败；实现控制器返回结果接受标记、content 自动复制守卫、面板与弹窗开关、串行持久化；独立审查修复旧 toast 残留；回归 Python/Node 和真实 Edge 引擎的合成页面流程；独立构建 v1.2.1，保留 v1.2.0。

测试边界：模型及网页均为模拟，剪贴板写入捕获替代真实系统写入，未调用付费 API。用户 Edge 安装和真实 X 验收仍受电脑操作工具限制，不能据此宣称已安装或真实网站通过。
