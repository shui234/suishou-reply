- 普通原创按选题取内置、已核验的官方参考资料；热点仍按现有流程获取近期官方消息。参考文档不冒充新消息，核验日期不冒充发布时间。

- 复制操作统一输出正文、换行和真实来源 URL。旧版无来源记录继续可读，不为旧内容随意补造链接，提示重新生成。
- 用模拟 API 回归出处、长度、默认复制、旧记录、历史、原有回复；实际 EXE 自检和窗口截图；更新说明，打包 v1.1.1 并本地提交。
