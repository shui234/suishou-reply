# v1.0.0 发布前安全检查

检查日期：2026-11-08。范围：拟提交源码、文档、脚本、截图及 Windows ZIP 发布包。此记录是一次发布内容检查，不等同于完整渗透测试或第三方依赖漏洞认证。

## 结果

- 未发现真实 API Key、GitHub Token、账户密码、用户配置、日志或剪贴板历史。
- 测试中匹配到的密钥形状字符串为明确的合成测试数据，用于验证过滤规则；应用默认不会使用这些字符串访问 DeepSeek。
- 发布包没有 `.git`、虚拟环境、构建缓存、日志或运行时配置，ZIP 文件完整性检查通过。
- 已检查 EXE 的 PyInstaller 归档、Python 字节码与依赖内容，未发现开发者的 Windows 用户目录或项目绝对路径。第三方 Qt 库含有供应商编译路径和 PEM 格式解析常量，不含相应私钥正文。
- API Key 通过 Windows Credential Manager 保存；偏好配置只允许模型、风格、主题字段。应用网络目的地固定为 DeepSeek 官方 HTTPS 接口，禁止自动跟随重定向。
- Git 忽略规则排除 `dist/`、`build/`、压缩包、可执行文件、密钥文件、配置、缓存与日志。可执行文件通过 GitHub Releases 分发。
- README 界面图来自实际程序的离线自检，图中只含合成推文与模拟回复。
